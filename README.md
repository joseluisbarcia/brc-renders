# brc-renders

Vídeos de BRC Studio ya publicados o programados (carpeta `v/`), con su portada. El nombre empieza por la fecha de publicación.

## Cómo descargarlos
- **Uno:** entra en la carpeta `v/`, pulsa el vídeo y luego el botón de descarga (flecha hacia abajo, arriba a la derecha).
- **Todos:** en la página principal del repo, botón verde **Code** → **Download ZIP**.
- **En el móvil:** abre el enlace del vídeo en el navegador, pulsa **View raw** y mantén pulsado el vídeo para guardarlo.
